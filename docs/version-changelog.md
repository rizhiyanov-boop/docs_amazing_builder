# Версия приложения и журнал изменений

Версия отображается в подвале на всех экранах DocBuilder. По нажатию открывается журнал изменений без дат. Последняя версия находится сверху и отмечена как текущая.

Источник номера версии — package.json. Текущая версия разработки: 1.3.0. История 1.2.0–1.2.3 восстановлена по изменениям версии и коммитам Git.

Описания находятся в src/releaseNotes.ts: номер версии, короткий заголовок и список изменений. При подготовке следующей версии нужно обновить version в package.json и корневых метаданных package-lock.json, затем добавить новую запись в начало RELEASE_NOTES. Даты в записи не добавляются.

Интерфейс находится в src/components/workbench/WorkbenchFooter.tsx. Закрыть журнал можно кнопкой «Закрыть», клавишей Escape или нажатием на фон. Диалог использует стандартное модальное окно браузера с удержанием фокуса.
